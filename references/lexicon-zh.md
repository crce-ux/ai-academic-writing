# 中文词表（译自 Academic-Humanizer）

**来源**：`junbolian/Academic-Humanizer`，MIT，Copyright (c) 2026 Junbo Lian。原文件 `academic-humanizer/references/lexicon.txt` 与 `references/chinese.md`。本文件是译文，并按本项目的组号重新归并。

**怎么用**：每个类别后标 `check_phrases.py` 的组号。组号即机检位置，改词表先改本文件，再同步脚本。

**与原文的差别**：原文按脚本的类别名（`zh_boilerplate` 等）分组；本文件按本项目的二十四组归并，跨类的词条只进一个组，避免同一句话报两次。

## 一、套话（组 2）

**开头**

- 近年来
- 随着……的快速发展 / 迅速进步 / 不断普及 / 蓬勃兴起
- 受到了……的广泛关注 / 日益重视 / 越来越多的关注
- 在当今时代 / 在……的背景下

**意义**

- 具有重要的理论意义和现实意义
- 具有重要的实践价值
- 填补了……的空白
- 为……提供了新思路 / 新视角 / 参考 / 借鉴 / 启示 / 决策支持
- 奠定了……基础
- 开辟了……新路径 / 新方向 / 新领域

**口语起手式**

- 说白了
- 说穿了
- 先说结论

**强调式递进**

- 不仅……更……
- 既……又……还……

处置：删。开头套话换成具体问题：谁在什么条件下做什么决策，难点在哪里。

## 二、比喻与流行语（组 4）

**流行语**

赋能、抓手、底层逻辑、顶层设计、痛点、打通、护城河、双刃剑、组合拳、助力、打造、深耕、破局、基石、蓝图、全方位、多维度、深度融合、新范式、新格局、新赛道

**拟人喻体**

- 像一位智慧的导师
- 相当于一个永不疲倦的初级审查员
- 贴身的数字秘书

拟人喻体的句式：喻体在前，后面跟一串褒义修饰，或跟「不仅……更……」。改为它实际做了什么，例如「它在几秒内逐条核对约束与数据」。

**待核对**（一般行文里是比喻，部分领域是术语）

闭环、链路、引擎、生态（圈 / 系统 / 体系）、桥梁、电池、画像

**保留的术语**（即使起源于比喻）

瓶颈、光环效应、溢出效应、维数灾难、冷启动、热启动、信噪比、启发式算法、闭环控制（控制论）、链路（通信）

判据：该词在领域内或本文中有定义。有定义则保留，无定义则改为它所指的机制或对象。

## 三、翻案腔（组 6）

- 不是……而是……
- 并非……而是……
- 不在于……而在于……
- 与其说……不如说……
- 看似……实则……
- 表面上……实际上……
- 你以为……其实……
- 说到底
- 答案恰恰相反
- 回头才发现

处置：直接从正面下判断。被推翻的一方确实是文中引用或交代过的观点时保留，写法见 `defensive-writing.md` 的附二。

## 四、冗余动词（组 7）

- 对……进行（分析 / 研究 / 探讨 / 讨论 / 优化 / 求解 / 估计 / 检验 / 比较 / 考察 / 计算 / 建模 / 评估 / 介绍 / 说明 / 阐述 / 改进 / 验证）
- 进行了……
- 加以（分析 / 研究 / 说明 / 解决 / 讨论 / 改进 / 验证）
- 对……作出了贡献
- 实现了……的提升

处置：还原为动词。「对模型进行求解」写「求解模型」；「作出了贡献」写具体做了什么。

依据是简洁。实测这类轻动词在 AI 文本里并不多见，不当作 AI 痕迹的判据。

## 五、空洞强调（组 10）

- 值得注意的是
- 需要指出的是
- 需要强调的是
- 需要说明的是
- 不难发现
- 不难看出
- 显而易见
- 众所周知
- 毋庸置疑

处置：删。直接陈述事实，事实是否重要由它的位置和证据体现。

## 六、连接词（组 9）

**连续几句或连续几段开头时处理**

此外、另外、同时、与此同时、而且

**保留**

因为、由于、因此、所以、从而、相反、例如、在……条件下

**「但」「但是」（组 26）**

「但」「但是」把限定挂在肯定句后面，前面那句就被读成要打折。重要就独立成句，不重要就删。关系改由分号、句号或冒号承担。「不但…而且」「但凡」不算。

处置：附加性的连接词移到主语之后，或改为句间实际关系，或删去。

## 七、提示语冒号（组 18）

- 一句话总结：
- 简单说：
- 总结：
- 小结：
- 结论：
- 核心是：/ 核心在于：
- 关键是：/ 关键在于：
- 重点是：
- 原因如下：
- 答案是：
- 本质上：
- 换句话说：
- 也就是说：
- 我的观点：/ 我的判断：/ 我的结论：

处置：提示语不承担信息时删去，把后面的话直接说出来。承接上文时保留，把冒号换成逗号或句号。

**保留的冒号**：引出原话、定义、公式，以及总说之后引出分说（「模型包括两部分：测量模型和结构模型」）。

## 八、翻译腔（组 19）

- 对于……来说
- 对……而言
- 就……而言
- 在……方面
- 这意味着 / 这表明 / 这说明
- 「一个 / 一种 / 一套 + 长定语 + 的 + 名词」

处置：对象直接放到主语位置，删去壳子；长定语拆成两句话。

**保留**：表示数学或实验条件的「当……时」（「当 n ≥ 2 时」「当且仅当」）。删去后时间关系变模糊的也保留。

## 九、元叙事（组 20）

- 本节将介绍 / 讨论 / 阐述 / 给出 / 分析
- 下面我们将……
- 接下来我们将……
- 如前所述 / 前文已经提到
- 本文结构安排如下
- 其余部分安排如下
- 本节小结 / 本章小结 / 小结一下

处置：只谈文本自身、没有内容的句子删去。包着实质结论的，只留结论：「如前所述，该上界是紧的」写「该上界是紧的（命题 2）」。

**保留**：全文结论部分的小结；指向读者此刻需要的内容的交叉引用。

## 十、工作日志（组 21）

- 健全性检查 / 合理性校验 / 完整性检查
- 流水线 / 管线
- 审计
- 验证协议 / 核验流程 / 认证环节
- 认证上界 / 认证解
- 护栏 / 兜底 / 回退机制 / 重试
- 从未触发 / 没有触发
- 随机种子 / 种子值
- 容差 / 迭代上限 / 时间上限
- 残差为 / 小于 / 低于
- 抖动项取 / 正则化参数设为
- 数值验证 / 经数值检验
- 脚本名、代码文件名

处置：写成方法、结果和论证。依赖计算的证明步骤写成引理加证明，并写明是精确计算还是浮点计算。

**保留**：报告结果所依赖的取值——模型参数与超参数、样本量、重复次数、数据来源与版本、停止规则、软件与版本、硬件（报告运行时间时）、代码与数据可得性声明。

## 十一、杜撰标签（组 22）

**中心词**

机制、体系、框架、范式、闭环、协议、架构、护栏、底座、中台、飞轮、管线、流水线

**判据**：抽象修饰语加中心词，全文出现不超过两次，同句没有定义，又不在下面的白名单里。

**白名单（跳过）**

- 机制：注意力、门控、定价、分配、拍卖、激励、匹配、投票、选择、传导、作用、形成、反应、病理、生理、药理、神经、分子、免疫、代偿、防御、调节、奖赏、多巴胺、胆碱能、补偿、奖惩、疗效、发病、致病
- 体系：理论、概念、分析、研究、贝叶斯、监管、法律、建模、评价指标、指标、标准、知识、学科、课程、诊疗、医疗、卫生、监测
- 框架：理论、概念、分析、研究、贝叶斯、监管、法律、建模
- 架构：网络、模型、系统、软件、计算
- 协议：通信、加密、网络、共识、实验、临床、访谈、调查、治疗、知情同意、随机、采集、分割、扫描、成像、重建、配准
- 闭环：控制、反馈
- 范式：研究、计算、科学、实验
- 管线：数据、处理、分析、影像、生信

处置三选一：

1. 文中写明了标签做什么 → 改为写这件事。
2. 文中没写 → 保留标签，在报告里建议作者写出步骤或改用普通名词。不替作者补步骤。
3. 只是给已有名字换了个说法 → 改回原名。

修改稿不得新增这类标签。

## 十二、主张强度（组 23，只报不判）

- 显著 / 显著地
- 首次
- 极大地
- 有效地解决
- 证明
- 最优
- 稳健 / 鲁棒

判据：

- 「显著」所在段落没有交代检验（p 值、置信区间、t 检验、方差分析、秩和、卡方、效应量、多重比较校正）→ 报。没有检验时给出差值并删去「显著」。
- 「最优」所在段落没有交代条件（命题、定理、引理、假设、在……条件下）→ 报。
- 「证明」只用于本文给出证明的定理、命题、引理。数值与实证结果用「表明」「显示」「发现」，间接证据用「提示」「与……一致」。

## 十三、首创词（组 24）

首次、首创、国内外首次、尚属首次

判据：全篇三次以上即报。「首次」只在作者确实检索过文献时保留，全文至多一次。

## 十四、自贬与防御（组 1、11、14）

**自贬**

- 本文只是初步尝试 / 仅仅是
- 初步的探索 / 粗浅的思考
- 抛砖引玉
- 笔者水平有限
- 不足之处敬请指正
- 难免存在……

**防御**

- 本文并不试图 / 声称 / 旨在 / 打算
- 超出了本文的研究范围
- 在一定程度上可能 / 或许可能 / 可能也许（叠用限定）

处置：删。已经证明或已经报告数字的结果按结果陈述；只有间接证据、超出样本的外推和猜想保留限定。

## 附一、来源中的实测比率

原项目的语料是中文非虚构写作，300 篇 AI 文本（5 个模型）对 329 篇人类文章，按每千字计。

| 特征 | AI | 人类 |
|---|---:|---:|
| 翻案腔 | 0.73 | 0.22 |
| 提示语冒号 | 0.29 | 0.08 |
| 空转句 | 0.29 | 0.03 |
| 顿号罗列过密 | 3.21 | 1.78 |
| 序数词当小标题 | 0.19 | 0.06 |
| 段首零主语评论（占非首段） | 0.61% | 0.14% |
| 相邻句同款（每百段） | 9.41 | 4.81 |
| 句长变异系数 | 0.58 | 0.67 |
| 比喻 | 1 | 2.4 |
| 破折号 | Claude 4.25 / DeepSeek 5.16 / Kimi 2.32 / Gemini 0.51 / GPT 0.11 | 0.80 |

⚠️ 语料是中文非虚构，不是学术文本，原项目未公开语料与统计方法。上表只用来判断方向，不作为本项目的阈值。

## 附二、不作为改写理由

下列特征看起来像 AI 味，原项目的实测显示没有差异或人类用得更多。改了反而更不像人写的。

- 句长、段落长度不够参差（变异系数 AI 0.58、人类 0.67）
- 被动句、名词化、长句本身（「被认为」「被视为」类抽象被动在 AI 文本中 0.09/千字）
- 反复写全称、少用代词（人类更常重复同一名词）
- 句内同构排比（「提升效率，降低成本」）
- 正文问句、问句小标题（人类正文问句远多于 AI）
- 正文里的「首先……其次」、句中的「第一，」
- 单字虚词（就、很、了）与口语连接词偏少

判据见 `revision-discipline.md`。
