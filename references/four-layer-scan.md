> **管什么**：词 / 句 / 段 / 章，哪一层有机器腔。

## 〇、管什么，不管什么

| | |
|---|---|
| **管** | **表达层**——去掉机器味，恢复研究主体与动作 |
| **不管** | **不新增**信息、事实、方法、指标、结论、落点或格式 |

> 🔴 **规则：只改表达，不改事实。**
> 组织层面的「边界声明过重」「研究动作不清」可以改写法，**但不能补写内容**。

## 一、四层扫描框架

从外到内四层，**逐层扫，不要跳层**。

### 第 1 层 · 词语

| 模式 | 处置 | 例 |
|---|---|---|
| 套话 | 删 | 随着社会的发展 · 越来越受到广泛关注 |
| 抽象标签 | 还原为**原文已有的动作** | 具有重要理论意义 · 是本研究的关键抓手 |
| 连接词堆砌 | 拆 | 首先 / 其次 / 最后、因此 / 从而 / 进而 连环 |
| **元评论** | 删或合并 | **值得注意的是 · 需要指出的是 · 综上所述** |
| 临时造词 | 改写；**对象不确定则人工确认** | 四态终结 · 有界使用政策原型 |

> **「元评论」是这一层命中率最高的一类**——它就是通常说的「元语言过多」：关于文本自身的语言，压过了内容本身。

### 第 2 层 · 句法

| 模式 | 处置 |
|---|---|
| **伪对立**（「不是 A 而是 B」「不只是 A 更是 B」） | **真边界**：保留并弱化模板感<br>**伪对立**：把 B 放入主干<br>**同义递进**：合并，**不补事实** |
| 无主语流程句 | 补回**原文已有的**主体，不新增职责 |
| 嵌套括号 / 长分号串 | 拆成句流 |
| 八步以上箭头 | 按职责拆分 |
| **规格书句法**（同句堆动作 / 配置 / 版本 / 失败 / 验收） | 先保会影响复现的字段，再按职责拆；**字段若含阈值 / 权限 / 分母 / 失败处理，不得删** |

### 第 3 层 · 段落

| 模式 | 说明 |
|---|---|
| **工程协议腔** | 入口 / 出口 · 状态映射 · 队列 · 载荷 · 闸门 · 终态 · 整包 · 静默补写 · 失败码——连续出现时**恢复研究主体和动作**；确属实现细节则保留并**首次中文释义** |
| 中英项目语域混杂 | 改为「**中文总括 + 必要英文括注**」 |
| **边界压过动作** | 通篇讲约束，却看不出**做了什么研究** |
| 口号 / 模型自我辩护 | 删除或合并 |
| **连续动词无主语** | 「归入、映射、锁定、冻结、收缩、降级」连用却无研究人员 / 评分者 / 数据管理员作主语 → **补回原文已有主体** |

### 第 4 层 · 章节 ⭐ **最容易漏，也最重要**

建立「事实 — 首次完整定义 — 后续引用」表，按章节职责区分。

**规则**：冻结、污染、样本、边界规则**只在一个章节完整说明**，其他章节保留本节必需的短句；**疑似有意重复则人工确认**。

> ⚠️ **本层的动作顺序是「先归位，再润色」。**
> 若段落本身放错了章节，逐行润色无效。

## 二、⭐ `section_roles`：章节职责表（**本法的核心**）

**这是全法最容易被漏掉、也最关键的一张表**——它决定第 4 层的判据：**这段话该不该待在这一章。**

| 章节 | 职责 |
|---|---|
| **立项依据** | **问题驱动，明确研究缺口** |
| **研究内容** | 说明**研究动作、边界、步骤和验证口径** |
| **研究基础** | 按**证据链**写清已有结果与局限 |
| **工作条件** | 将**资源逐项对位到研究任务** |
| **风险应对** | 说明**风险、触发条件、影响和备选方案** |
| 通用 | 只按原文职责判断，**不强行套用其他章节结构** |

### 用法

**逐个段落问：这一段在写什么？它该待在这一章吗？**

> **实测案例**：一份标注为「立项依据」的文本，四段里有**三段**在写技术流程、设计参数、统计假设——**全是「研究内容」的职责**。
> 而真正该写的「研究缺口」只有一句。

## 三、术语三分法

同一份文本里的术语，分三类处理：

1. **必须保留的**——学科标准术语、计量单位、量表名
2. **必须释义的**——自造词、缩写、跨领域借用的词（**首次出现处给中文释义**）
3. **必须还原为动作的**——把动词名词化造出来的抽象标签（「进行了分析」→「分析」）

### ⚠️ 补一类：被抹平的术语要**补回来**

第 1 类不只用来「别删」，还用来**倒查**——AI 改写的常见动作是把正式术语摊成日常说法：

| 被摊平的 | 该补回的 |
|---|---|
| 患者按医嘱吃药的程度 | **依从性（adherence）** |
| 因为停药而重新发病 | **复发（relapse）** |
| 两组之间会不会有关系 | **组间关联 / 差异** |
| 把数值调整到同一个范围 | **归一化** |

**四条判据**：

- 摊平后**变长**且**更含糊**——这是信号，不是同义改写
- **量表名、诊断标准名、统计量名一律不摊平**（PANSS 就是 PANSS）
- 摊平后同一概念在全文出现多种说法 → 必补
- ⚠️ **方向不许反**：补术语**不改变原意**；拿不准就报出去，**不擅自换名**

> **来源**：`matsuikentaro1/humanizer_academic`（MIT）记的是医学稿的同一个动作——
> 去味不只有「删」，还有「**把 LLM 一律抹平的正式术语恢复回来**」。
> 我们原先只做了「删」。

## 四、回归样例

改完后，用同一份文本跑一遍第 1–4 层，确认没有引入新问题：
- 改过的句子是**新文本**，须重新扫描（与迭代自查的「修正回归」同理）
- 特别检查：拆句后有没有留下悬空的指代、丢失的主语、断掉的逻辑连接
