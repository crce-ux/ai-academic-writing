# 轴三 · 文体适配

> **来源**：作者原创，来自其自身写作复盘——一次 87 处口语化清理的实证归纳。
> **管什么**：这句话放在**这个文体**里，对吗？

---

## 一、最重要的前置：文体决定判据

同一个词，在讲稿里可能是对的，在幻灯片上就是错的。

| 文体 | 要什么 | 怎么查 |
|---|---|---|
| **幻灯片文字** | **书面、简洁、自足** | 全表适用——听众**线性跳读，没有上下文兜底** |
| **讲稿 / 备注** | **口语、能一口气念完** | **只适用「必删」**；口语动词与节拍**保留** |
| **论文 / 标书正文** | **书面、有出处、动作清楚** | 全表适用，另加 `four-layer-scan.md` |
| **对外邮件 / 微信** | **简洁直给、不越级承诺** | 主要过 `persona-match.md` |

```
幻灯片：宁可干一点，也不要"讲得热闹"——听众是跳读的
讲稿：  宁可口语一点，也不要"念论文"——你是说给人听的
```

> ⚠️ **不先定文体就下手改，会在另一个维度上把稿子改坏。**
> 这是本 skill 的第 0 步，不是可选项。

---

## 二、最容易搞反的一条：**口语节拍 ≠ 口语化**

| ✅ **保留**（节拍） | ❌ **清理**（口语化措辞） |
|---|---|
| 「**三条原因。**」——小节起拍 | 「**卡在哪**」——口语动词 |
| 「**一共四条**，我都先说在这里。」——回指清楚 | 「**分量最重**」的一篇——程度夸张 |
| 「前三条早就成立，第四条刚刚才成立。」——紧接上文 | 「那**唯一的那一篇是什么**？」——自问自答 |

**判据：它在承担节奏功能，还是在偷懒？**

承担节奏的短句、省略，**补全反而拖沓**——这是讲稿的优点，不是缺陷。

## 三、必删（两种文体都清）

| 类型 | 例 | 为什么 |
|---|---|---|
| **降智解释** | 「**这句话的意思是**：…」「也就是说，…（重述一遍）」 | **不哄**——把它写清楚，而不是加一句翻译 |
| **自问自答** | 「那**唯一的那一篇是什么**？——是 Altar 1986。」 | **不设问**——你会当众自问自答吗？把答案直接写出来 |
| **空泛夸张** | 「**极其**重要」「**非常**显著」「**分量最重**」 | 程度靠**证据**给，不靠副词 |
| **非科学措辞** | 「氯氮平**为什么独**」「**卡在哪**」「**绕不开**」 | 换成科学表述：「独特疗效的来源」「该环节的瓶颈」「必须纳入」 |
| **演义 / 媒体化** | 「进口**双雄**」「仿制**大军**」「价格战**混战**」「**领跑**」「**抢跑**」「**洗牌**」「权重**跳水**」 | 直述规模与主体：「**已获批 6 款，国产 4 款**」「**十余家企业已提交申请**」「**首款获批**」「**价格由 1,893 元降至 987 元**」 |

> **演义 / 媒体化**一类的判据：
> **这句话能出现在期刊论文或药监局公告里吗？不能，就重写。**
> 引申号（「」""）包裹的比喻性词汇同样算——**不要用引号给口语词上保险**。
> 陈述分歧或竞争时用中立动词：**申报 / 获批 / 受理 / 授权 / 共同开发**。

> 这五类**在讲稿里也删**——口语不等于不精确。

## 四、幻灯片专用（讲稿可保留）

| 类型 | 例 | 改成 |
|---|---|---|
| **标题替听众下结论** | 「两条线各自成熟，交叉处为空」「这不是『没人想到』」「从关联到因果」 | **直白写明本页讲什么**——标题**只标内容、不表态**。⚠️ **页标题与页内落点分开**：结论放**页内落点** |
| **指示听众怎么读** | 「下表只回答一个问题：…吗？」「先看…再看…最后看…」、表格列名写成问句 | **直接给内容**。表头写清**表是什么**，列名用**名词**。⚠️ **听众不是不会看表** |
| **用指代代替点名** | 「那套方法」「那篇文章」「该轴」「这五条」 | **每处引用点名**「第一作者 ＋ 年份 ＋ 刊名」；指代对象**就地重述**。⚠️ 幻灯片与口播**不是线性阅读**，听众翻不回去 |
| **落点后再补一句解释** | 「这两条是链③ 的全部立足点」「这个形状本身就是结论」 | **落点说完就停**——不追加「所以这很重要」式总结。⚠️ 同一件事讲两遍就是注水 |
| **贴「类型」标签** | 「类型：人体·关联 / 动物·因果」 | **改标「研究方法」**——「结构 MRI 体积测量 ＋ 中介分析」。⚠️ 标签只说「这算哪一类」，**研究方法才是别人能拿去用的** |
| **口语动词** | 卡在、绕不开、踩坑、跑通、钉死 | 受限、必须纳入、存在问题、验证通过、确定 |
| **程度词** | 特别、相当、挺、蛮、有点 | 删，或换具体量级 |
| **第一人称口语** | 我觉得、咱们、说白了、其实 | 删 |
| **指示代词起句** | 这个、那个、这边 | 补全指代对象 |
| **口头连接词** | 然后、接下来、所以呢 | 靠**排版**表达顺序，不靠连接词 |

## 五、出稿前人工过

机检查不到的，靠人：

- [ ] 逐页问：**这句是在承担节奏，还是在偷懒？**
- [ ] 讲稿：**念一遍**，磕巴的地方是写的问题
- [ ] 幻灯片：**想象跳读**——单看这句，知道说啥吗？
- [ ] 有没有「降智解释」和「自问自答」？（这两类机检容易漏）

## 六、与其它轴的边界

| 轴 | 管什么 |
|---|---|
| **本文件** | 措辞的**文体适配**（口语化 vs 书面 / 节拍 vs 偷懒） |
| `defensive-writing.md` | **叙事姿态**（是不是在替审稿人攻击自己） |
| `four-layer-scan.md` | **词句段章的形式**（机器腔、章节归位） |
| `persona-match.md` | **像不像这个人写的**（术语 / 引据 / 立场） |

> **别把这几条轴混着用**——每一轴管一件事，混了就会互相误报。
> 例：讲稿里的「那篇综述」是对的，幻灯片里是错的。
