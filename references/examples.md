# 正反样例

六组对照。**左边踩了规则「改表达，报内容」，或过不了 `negation_diff.py`。**

---

## 一、表达层可改 vs 内容层只报

### ❌ 不好（把内容层也改了）

```
原文：两组差异不显著（p=0.08）。
改写：两组差异未达统计学显著（p=0.08），提示可能存在趋势。
```

**「提示可能存在趋势」是原文没有的论断**，属替作者造结论。

### ✅ 好

```
表达层（改）：
  原文：本文旨在探讨屏状核在 TRS 中的潜在作用，具有重要的科学意义。
  改写：本文检验屏状核连接能否在治疗前区分 TRS 应答者。

内容层（只报，一个字不改）：
  ⚠️ 第 3 段「两组差异不显著（p=0.08）」——**p=0.08 是否预注册的阈值？**
     若预注册为 p<0.05，此处应报为「未达阈值」而非「不显著」。
     核验路径：对照注册记录 NCT04xxxxxx 的主要终点定义。
```

**差在**：表达层给改写；内容层**报位置、报类型、报理由、给核验路径**。

## 二、引用幻觉：文献存在 ≠ 它说了你引用的内容

### ❌ 不好

```
已有研究证实屏状核连接下降可预测氯氮平疗效（Zhang 2026）。
```

反查：PMID 存在，DOI 对得上，**语境四级判为 WRONG**——
原文说的是「相关」，且是横断面设计，**没有预测**。

**三态核验会放过它**（存在 = 已核实），所以必须走语境四级。

### ✅ 好

```
已有研究报告屏状核连接与氯氮平疗效相关（Zhang 2026，PMID 41234567，
横断面，相关非预测）。

语境四级：SUPPORTS（原文摘要原文：「connectivity correlated with
ΔPANSS across 12 weeks」）
```

**差在**：把「证实…预测」降回原文的「相关」；**语境判定单独记**。

## 三、否定翻转（最隐蔽的一类）

### ❌ 不好

```bash
# 润色后
原文：两组差异不显著（p=0.08）。未发现剂量效应。
改写：两组差异显著（p=0.08）。剂量效应有待验证。
```

**数字一个没动，`check_token_diff` 全过**——但结论反了。

### ✅ 好

```bash
$ python scripts/negation_diff.py 原稿.md 润色后.md

  否定短语：原文 2 种 / 改写后 0 种

  【原文有、改写后没有 —— ⚠️ 最危险：可能把否定改掉了】2 条
    · 「不显著」
    · 「未发现剂量效应」

  共 2 条。⚠️ 只报「对不上」，不判该不该改。
```

**差在**：改完先跑一遍否定比对。**它只报对不上，改不改由人定**。

## 四、身份匹配

### ❌ 不好

```
（作者是本科在读，稿件的讨论段）
本研究为领域内首次系统揭示屏状核在 TRS 中的作用机制，
填补了该方向长期以来的理论空白。
```

**这个身份的人写不出这句**：过度自称、绝对化（「首次」「填补空白」）、
且「作用机制」本研究根本没做。

### ✅ 好

```
本研究在 TRS 人群中检验了屏状核连接与疗效的关联。
据文献检索所及（检索式见附录 A，截至 2026-09-30），
尚未见在氯氮平抵抗亚群中检验该关联的报道。
```

**差在**：`首次` → 「检索所及尚未见」，并给出**检索式与截止日**——
可核查，可反驳。

## 五、文体分叉：论文 / 综述

| | 论文（IMRaD） | 综述 |
|---|---|---|
| 一个段落的任务 | 报告本研究做了什么、看到什么 | **综合别人做了什么，并给出判断** |
| 四种句子 | 论断 / 证据 / 判断 / 过渡 | 同，但**判断句的比例高得多** |
| 自我引用 | 主体 | 极少——除非确有必要 |
| 写作顺序 | 引言 → 方法 → 结果 → 讨论 | **主体 → 整合讨论 → 引言 → 摘要** |
| 自称 | 「本研究」 | 名头必须与配置自洽（叙述性 / 系统 / 范围） |

> ⚠️ 写「系统综述」却给不出 PRISMA，**比写「叙述性综述」问题更严重**——承诺了没兑现。

## 六、AI 声明

### ❌ 不好

```
（不声明。被抓到时说「只是润色，不算 AI 写作」。）
```

### ✅ 好

```
AI 使用声明：
本稿的英文语言润色使用了 Claude（Anthropic），
用于改善表达流畅度；**研究设计、数据分析、结果解释与结论
均由作者完成**，AI 未参与内容生成。
作者对全文内容负责。
```

**差在**：写清了**用在哪一步、没用在哪些步骤**。
