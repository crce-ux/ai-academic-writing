# ai-writing-debug

[![Structure](https://github.com/crce-ux/ai-writing-debug/actions/workflows/structure.yml/badge.svg)](https://github.com/crce-ux/ai-writing-debug/actions/workflows/structure.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**学术文本中 AI 写作的诊断与审查**

- **表达层**——防御性写作、机器腔、文体错配、代笔身份错配。定位到句，给出改写。
- **内容层**——引用幻觉、论断越界、数字漂移、定位虚设。只报不改，给核验路径。

---

## 它补的是什么

市面上的工具几乎只做一件事：**给分**。告诉作者「这段 AI 味重」——然后作者看着那句话，改不动。

这个 skill 做另外两件事：

| 层 | 给什么 |
|---|---|
| 表达层 | **改写**——那句话能直接粘回去 |
| 内容层 | **核验路径**——回原文/回数据库自己核，不代改 |

---

## 两层八轴

| 层 | 轴 | 问的问题 |
|---|---|---|
| 表达 | ① 叙事姿态 | 这段是不是在替审稿人提前攻击自己？ |
| 表达 | ② 表达层 | 词 / 句 / 段 / 章，哪一层有机器腔？ |
| 表达 | ③ 文体适配 | 这句话放在**这个文体**里对吗？ |
| 表达 | ④ 身份匹配 | **这个身份的人**，写得出这句吗？ |
| 内容 | ⑤ 引用幻觉 | 引的文存在吗？原文说过这句吗？ |
| 内容 | ⑥ 论断越界 | 结论比证据大吗？ |
| 内容 | ⑦ 数字漂移 | 同一个数跨节一致吗？口径标了吗？ |
| 内容 | ⑧ 定位虚设 | 声称的「首次」，真的没人做过吗？ |

⚠️ **混着查会互相误报。** 分轮查。

---

## 为什么内容层要单立

表达层问「这话像不像 AI 写的」，内容层问「这话对不对」。两个问题会**各自漏**：

- 表达层漏检 → 读起来像机器，但内容是真的
- 内容层漏检 → 读起来很顺，但引的文不存在、结论比证据大

**AI 生成的学术文本，第二类错得更多，也更难发现**——因为它读起来是通的。

内容层不查抽象的对错，查四件能落地的事：

```
⑤ 引文反查三步   存在性 → 归属 → 强度
                  （存在 ≠ 支持，这是最常见的漏检）
⑥ 论断强度比对   把这句话的证据摆出来，撑得住吗
⑦ 数字跨节对齐   摘要/正文/图表同一个数是否一致、口径标没标
⑧ 空白当检索做   把声称的「首次」当成一次检索任务做一遍
```

## 一条最容易搞反的原则

**口语节拍 ≠ 口语化。**

| ✅ 保留 | ❌ 清理 |
|---|---|
| 「三条原因。」——小节起拍 | 「卡在哪」——口语动词 |
| 「一共四条，先说在这里。」——回指清楚 | 「分量最重」——程度夸张 |

**判据：它在承担节奏功能，还是在偷懒？**

同一条规则的判法**随文体翻转**——「那篇综述」在讲稿里可以，在幻灯片上必须点名（听众翻不回去）。
所以工作流第 0 步是**定文体与身份**。这一步不定，后面全是误报。

---

## 🔴 铁律：改表达，报内容

**表达层**：不新增信息、事实、方法、指标、结论、落点或格式。

**内容层**：**一个字都不改**。发现问题 → 报位置、报类型、报理由、给核验路径。

> 替作者改内容层的一个字，就等于替他造事实。

---

## 与相邻工具的边界

| | 管什么 |
|---|---|
| 本 skill | **自己的稿**（尤其含 AI 生成）——表达可改，内容只报 |
| `peer-review` | **别人的稿**——评议性质，不出改稿 |
| `ai-writing-detection` | 只做检测打分，不做修复 |
